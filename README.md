## 🧪 `lab_work/`

### `lab_1`: Sequence Termination Logic  
Enter a number `G`. Then enter a sequence of integers, ending with `G`. Count all entries, count positives, sum and multiply negatives (if any).

### `lab_2`: Average Proximity Finder  
Enter `N` numbers, calculate average, and find the two closest numbers: one below and one above the average.

### `lab_3`: Reverse Word Characters  
Read a text from a file, reverse the characters of each word (word order stays), and write the result to another file. Handles edge cases like missing files, too-long lines, etc.

### `lab_4`: Linked List – Top Scorer Remover  
Create a linked list of participants and scores. Remove the one with the highest score – only if user agrees. Uses modular structure with headers like `linked_list.h`, `input_validation.h`, etc.

Code example for the main logic is [here](lab_work/lab_4/main.c).  
(It's... a lot.)
